# بناء أدوات صغيرة دون برمجة

Building Small Tools without Code

مسار الطلاقة في البيانات والذكاء الاصطناعي · أكاديمية سدايا · USE-FLU-205 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يحوّل المشاركون ممن لا يبرمجون حاجةً لدى فريقهم، مثل متتبع للطلبات، إلى أداة داخلية صغيرة مختبرة باستخدام منصة للبرمجة التوليدية. ويحددون المستخدمين والبيانات والقواعد ومستويات الوصول، ويوجهون وكيل البرمجة عبر ملف تعليمات، ولا يقبلون أي تغيير إلا بعد اختباره، ويفحصون الأداة بحثًا عن البيانات المكشوفة والأسرار البرمجية (secrets) وغياب ضوابط الوصول، ثم يكتبون مذكرة تسليم. أما النشر في بيئة الإنتاج فمن اختصاص المطورين (DEV-SWE-201).

**الصيغة:** ورشة عمل: يومان في كل منهما أربع جلسات مع مختبرات، وعمل تحضيري موجه ومهمة بناء متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/use-flu-205/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يميّز بين النموذج الأولي للفريق ونظام بيئة الإنتاج، ويحدد الطلبات التي تحتاج إلى المطورين، استنادًا إلى ثمانية طلبات لبناء أدوات | Awareness | تصنيف صحيح لسبعة طلبات من ثمانية في إحدى الفئات: يُبنى، أو يُبنى بمراجعة من تقنية المعلومات، أو يُحال إلى المطورين |
| LO2 | يصوغ مواصفات في صفحة واحدة تحدد المستخدمين وحقول البيانات والقواعد ومستويات الوصول واختبارات القبول، استنادًا إلى حاجة اصطناعية لإعارة المعدات | Applied | مواصفات فيها خمسة معايير قابلة للاختبار على الأقل |
| LO3 | يستخدم منصة للبرمجة التوليدية وملف تعليمات لبناء الأداة بخطوات صغيرة مختبرة قابلة للتراجع، باستخدام المواصفات وبيانات اصطناعية | Applied | نموذج أولي يعمل وسجل تغييرات فيه نتيجة اختبار لكل خطوة |
| LO4 | يختبر النموذج الأولي بحثًا عن البيانات الشخصية المكشوفة والأسرار البرمجية المضمَّنة في الرموز البرمجية وغياب ضوابط الوصول والحسابات الخاطئة، على نموذجه الأولي ونموذج آخر فيه أعطال مدسوسة | Applied | سجل اختبار يكشف الأعطال المدسوسة ويوثّق الإصلاحات في نموذج المشارك |
| LO5 | يسلّم أداة داخلية مختبرة مع مذكرة تسليم تحدد المالك والبيانات المسموح بها ومستويات الوصول والحدود ومتى يتولى المطورون الأداة، استنادًا إلى حاجة لدى الفريق، وعلى بيانات اصطناعية | Performance | عرض حي للأداة مع إعادة تشغيل اختبار يختاره المقيِّم |

## المتطلبات السابقة

- USE-FLU-201 العمل مع المساعدات الذكية: التفويض والوصف والحكم وتحمل المسؤولية
- يُقبل المقرر USE-FLU-202 أيضًا بديلًا عن المتطلب
- ينظم البيانات في جداول ضمن جداول البيانات الإلكترونية، ولا يحتاج إلى معرفة بالبرمجة

## الأدوات

كل سطر قدرة، والأمثلة قابلة للتبديل.

- **منصة البرمجة التوليدية:** وكيل برمجة مفتوح المصدر في مساحة عمل معزولة, أداة معتمدة لبناء التطبيقات عبر المتصفح
- **مخزن بيانات للنموذج الأولي:** ملف SQLite محلي, جدول في جدول بيانات إلكتروني
- **فحص الأسرار البرمجية:** gitleaks، يشغّله الميسِّر, الفحص الأمني المدمج في المنصة
